# モバイルタイポグラフィ デザイン仕様

## ユーザーの意図

coarse pointer の iOS デバイスでは、入力欄に 16px-reference の最小サイズが自動的に適用されます。これに合わせて、その他のテキストスタイルとのバランスを整えます。

## デザイン原則

- **DR1 — 読み取り用ベース。** モバイルのベースは `M = max(B, 16)` でなければなりません（MUST）。16px-reference は `1rem` です。ユーザーがテキストサイズを設定している場合は、その値がこのベースに置き換わり、DR2 のピン留めは適用されません（`spec:AST-102` FR3）。
- **DR2 — ピン留め対象。** 選択されたロールはデスクトップのサイズを保持しなければなりません（MUST）。その他のロールは導出されたスケールに従います。

## 構成と階層

`B` はデスクトップのベース、`r` はその比率、`k` は生のステップ、`a` は選択されたピン留めステップです。

| デスクトップの比率 r | ピン留め対象、ステップ a | デザイン意図                                                                          |
| -------------------- | ------------------------ | ------------------------------------------------------------------------------------- |
| `r <= 1.25`          | Display 1、`+6`          | 読み取り用ベースが大きくなっても、コンパクトなスケールの display サイズを保持する。   |
| `1.25 < r < 1.414`   | Heading 2、`+2`          | Heading 2 を保持しつつ、より大きな display ロールを本文テキストに対して相対的に縮小する。 |
| `r >= 1.414`         | Heading 3、`+1`          | Heading 3 を保持し、狭い画面で display 階層が本文テキストを圧倒しないようにする。       |

必要なサイズの関係は次のとおりです。

```text
M = max(B, 16)
r_pin = r * (B / M)^(1/a)
desktop(k) = round(B * r^k)
mobile(k) = round(M * r_pin^k)
```

最も近い整数の reference pixel に丸めます。ちょうど中間の値は切り上げます。rem に換算する場合は 16 で割ります。丸める前の値で見ると、ピン留め位置より上のロールは縮小し、下のロールは拡大します（`B < 16` の場合）。

## 状態の表現

モバイル条件に該当しない場合は、デスクトップのサイズを保持します。
`B >= 16` かつテキストサイズが設定されていない場合、モバイルプロファイルはデスクトップのベースと比率をそのまま保持します。

## レスポンシブと入力の挙動

- **DR3 — 有効化条件。** デフォルトでは、モバイルは `(width < 1024px) and (pointer: coarse)` に一致しなければなりません（MUST）。

width はレイアウトビューポートを指し、coarse はプライマリポインターを指します。
`spec:AST-012` が定める実効的な `lg` ブレークポイントを使用します。標準値は 1024 CSS px で、上限は含みません。
ブラウザサポートとフォールバックは `spec:AST-013` に従います。ブラウザ固有の挙動については、そのブラウザでの実証が必要です。

## アクセシビリティの意図

- **DR4 — ルートのサイズ設定。** モバイルプロファイルはドキュメントルートのフォントサイズを変更してはなりません（MUST NOT）。

## 代表的な例

```text
B=14; r=1.333; a=2; M=16; r_pin=1.246907324142416
heading-2: 25→25px; body: 14→16px; display-1: 79→60px
```

### 検証

| 契約     | 検証内容                             | 代表的な状態                                 | 失敗のシグナル                       |
| -------- | ------------------------------------ | -------------------------------------------- | ------------------------------------ |
| DR2      | 比率と対象の対応関係をレビューする   | 1.25/1.414 の未満、ちょうど、超過            | 対象または境界の誤り                 |
| DR1, DR2 | 必要なサイズを比較する               | 計算例、B>=16                                | アンカーまたはベースの変化           |
| DR3      | 有効化条件を確認する                 | 狭い/広い × coarse/fine、ちょうど 1024px     | 論理積または境界の誤り               |
| DR4      | ルートのサイズ設定を確認する         | モバイルプロファイルの有効/無効              | ドキュメントルートのフォントサイズの変化 |
