# 空間階層デザイン仕様

## ユーザーの意図

ユーザーが個々のラベルを読む前に、何と何がまとまっているのかを理解できるようにします。
情報密度の高い画面でも整理された状態を保てるのは、近接によって関係性が表現されているからであり、
すべてのグループを別のコンテナで囲んでいるからではありません。

## デザイン原則

- **DR1 — 近接は関係性を伝える。** 密接に関連する要素は、別の関心事どうしよりも近くに配置しなければなりません（MUST）。
- **DR2 — 分離はグループのレベルに応じて大きくなる。** 間隔は、ローカルなコンテンツからグループへ、グループからセクションへと大きくならなければなりません（MUST）。
- **DR3 — 囲みよりも余白を優先する。** 作成者は、カードや境界を追加する前に、余白と整列によってグループを形成すべきです（SHOULD）。
- **DR4 — 変化は意図的なものである。** コンポジションは、あらゆる箇所に同じ間隔を適用するのではなく、階層が見て取れるだけの空間的なコントラストを持たなければなりません（MUST）。

## 構成要素と階層

| 役割           | 目的                                                         | 必要な関係                                              |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| ローカル間隔   | ラベル、値、アイコン、コントロールを直接関係するコンテンツと結びつける | それを含むグループ間隔より小さい                        |
| グループ間隔   | 同列のコントロールやコンテンツグループを分ける               | ローカル間隔より大きく、セクション間の分離より小さい    |
| セクション間隔 | 異なる関心事を分ける                                         | スクイントテストでも判別できるほど十分に大きい          |
| 整列エッジ     | 行や領域をまたいで関連するコンテンツをつなぐ                 | 同じグループレベル内で一貫して繰り返される              |

## 状態の表現

空間的な関係は、データがある状態、データが少ない状態、空の状態、エラー状態のいずれにおいても知覚できなければなりません（MUST）。条件付きで表示されるコンテンツによって、グループの順序が崩れたり逆転したりしてはなりません。

## レスポンシブ対応と入力時の挙動

- **DR5 — リフローしてもグループを保つ。** 幅が制約される場合、コンテンツは縦に積み重ねたり移動したりしてもかまいません（MAY）。ただし、ローカル・グループ・セクションの関係は区別できる状態を保たなければなりません（MUST）。
- **DR6 — 動的なコンテンツでもリズムを保つ。** バリデーション、補足テキスト、任意のアクションは、それらが対象とするコンテンツと関連付けられたままでなければなりません（MUST）。

## アクセシビリティの意図

視覚的なグループ化は、セマンティックな読み上げ順序およびプログラム上の関係と一致させるべきです。グループにラベル、見出し、その他のセマンティックな境界が必要な場合、余白だけを唯一の手がかりにしてはなりません。

## 代表的な例

- フォームでは、ラベルとフィールドの間を最も近い関係とし、フィールド間にはそれより大きな間隔、セクション間には最も大きな間隔を設けます。
- ダッシュボードでは、カードを入れ子にする前に、余白と整列によって領域を分けます。
